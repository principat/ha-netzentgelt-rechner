# Netzentgelt-Rechner (Home Assistant)

Berechnet aus Ihren Langzeitstatistiken, wie sehr sich §14a-Modul 3, ein dynamischer Stromtarif, deren
Kombination und eine Speichererweiterung lohnen, und liefert das quartalsweise Netzentgelt als einen Sensor.

- Fachlich: `docs/01-fachliche-spezifikation.md`, technisch: `docs/02-technische-spezifikation.md`
- Tests: `docs/03-teststrategie.md`, Release: `docs/04-release-workflow.md`
- Installation: HACS → Benutzerdefiniertes Repository → Integration → „Netzentgelt-Rechner“ hinzufügen.
- Entwicklung mit Claude Code: siehe `CLAUDE.md`.

Dashboard-Beispiel: `examples/dashboard.yaml`.
